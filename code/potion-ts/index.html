Potion.ts

A short, runnable tour of the little language _why the lucky stiff wrote in 2009, reimplemented in TypeScript so it runs in your browser.

How to read this. Every code box is live: edit it and press Run. Cells in a chapter share their names from top to bottom, so a cell can use what the cells above it defined. Each chapter ends with a short exercise that checks itself.

The source code of this TypeScript reimplementation is at mblondel/potion-ts. It leaves out a few things the original has: continuations (here), files and networking, and the C foreign-function interface. The original lives at perl11/potion, and its README is still the best description of what _why was reaching for.
